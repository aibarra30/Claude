# Generar Reportes de Servicio

Generador en Python/ReportLab de PDFs de reportes de servicio semanales para Caterpillar, a partir de logs de WhatsApp.

## Stack técnico
- Python
- ReportLab

## Fuente de datos
- Logs de WhatsApp (registro de actividades de servicio)

## Cliente
- Caterpillar México

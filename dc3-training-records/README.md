# DC-3 / Constancia de Habilidades Laborales

Procesamiento de registros oficiales mexicanos de capacitación laboral (DC-3) para cursos de seguridad eléctrica y procedimientos de bloqueo/etiquetado (lockout/tagout).

## Funcionalidad
- Inserción de firmas extraídas de fotos usando numpy, ReportLab y pypdf
- Conversión de coordenadas entre pdfplumber (origen superior) y ReportLab (origen inferior)

## Stack técnico
- Python
- numpy
- ReportLab
- pypdf
- pdfplumber
